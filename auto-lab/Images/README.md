# Question Images

Drop the diagram images for the pretest here. The test panel automatically
shows them above the question text; if a file is missing, the question is
still fully answerable (the image area is simply hidden).

Expected files (named after the pretest item number):

| File    | Question                                                      |
|---------|---------------------------------------------------------------|
| q2.png  | #2  - DFA diagram: what state does 1101 lead you to?          |
| q3.png  | #3  - DFA diagram: what state does 00110 lead you to?         |
| q4.png  | #4  - DFA diagram: what state does 1010 lead you to?          |
| q5.png  | #5  - DFA diagram: rule of the language (even same digits)    |
| q11.png | #11 - Diagram: is it a valid DFA, why or why not?             |
| q12.png | #12 - DFA diagram: what is the rule? (ends in 1)              |
| q15.png | #15 - DFA diagram: transition symbols x, y, z (ends with 001) |

To point a question at a different file, edit the "image" field of that
question in `Testing/Data/question_bank.gd`.
